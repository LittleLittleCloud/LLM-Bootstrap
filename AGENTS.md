# Project instructions

Use English for project writing. Preserve literal test inputs, identifiers, commands, hashes, and raw evidence.

Read skills/bootstrap-experiment-sop/references/experiment-protocol.md and skills/bootstrap-experiment-sop/references/evaluation-protocol.md before planning, running, or reporting an engine experiment. Evaluation code and scripts are defined by this repository under evaluations/; experiments and builder LLMs do not write or change them. Skills are the project deliverable; engine implementations and hardware results belong to explicitly identified experiments.

Use feature branches with the codex/ prefix and pull requests. Merge only with explicit user authorization. Do not publish model weights, credentials, private prompts, or unreviewed agent transcripts. Record artifact hashes and access limitations instead.

Keep planned targets, prior external evidence, and measurements produced by this project's skills clearly distinguished. Do not claim SOTA, autonomy, or self-hosting without the corresponding evidence.
